# Self-hosted fonts

These heading fonts are not on a font CDN, so the app serves them itself. All of them are free to redistribute.

| File | Font | Author | License |
|------|------|--------|---------|
| `cantique.woff2` | Cantique | Velvetyne | SIL Open Font License 1.1 (`LICENSE-cantique.txt`) |
| `basteleur-bold.woff2` | Basteleur Bold | Keussel / Velvetyne | SIL Open Font License 1.1 (`LICENSE-basteleur.txt`) |
| `old-london.woff2` | Old London | Dieter Steffmann | 100% free (dafont.com). Converted from the original TTF to WOFF2. |
| `mirage-gothic.woff2` | Mirage Gothic | Carlos Mario Peña Solís | 100% free (dafont.com). Converted from the original TTF to WOFF2. |

Velvetyne files are the foundry's own WOFF2 releases, unmodified.
